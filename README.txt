APPLEBRIDGE ORGANIGRAM BUILDER
================================



IMPORTANT

- Organigrams are stored locally in the user's browser.
- Data will not automatically transfer between devices or different browsers.
- The Rajdhani and Roboto fonts load from Google Fonts, so an internet
  connection is required for those fonts to display.
- PDF export uses the browser's print window. Choose Save as PDF and keep
  the paper size set to A4 with Landscape orientation.

FILES

- index.html: main app
- styles.css: styling and A4 print layout
- app.js: organigram editor and reporting-line logic
- assets/: Applebridge company logos
